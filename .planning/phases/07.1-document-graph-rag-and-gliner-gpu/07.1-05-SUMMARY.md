  CUDA build did not complete and the user redirected experimentation. No measured evidence yet
  supports a permanent CPU or GPU choice.
- **Measure after fan-out.** Plan 06 must land before CPU throughput is reported; otherwise its

  benchmark. Model, quantization, adapter, concurrency, and device changes must not be conflated.
