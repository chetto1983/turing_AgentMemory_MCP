## Pattern Assignments

### Provider image and dependency lock

#### `docker/qwen-provider.Dockerfile` (NEW)

**Analog:** `docker/gliner-provider.Dockerfile:1-25`

Copy these repository conventions:

- use the already-vetted exact base
  `python:3.12-slim@sha256:423ed...99fbf`, never a floating `python:3.12-slim`;
- set a dedicated non-root `HOME` and Hugging Face cache below `/models/cache`;
- install before switching to the non-root user;
- run a package module as the entrypoint;
- keep the root filesystem compatible with Compose `read_only: true`.

Do **not** copy `docker/llama-provider.Dockerfile:1-15` beyond its “base image by
digest + non-root process” hardening. It is a CUDA/llama.cpp image and is the
retired architecture for this cutover.

The image should contain one implementation and be instantiated twice. Model
selection belongs to runtime `QWEN_ROLE`, not separate embedding/rerank images:

```dockerfile
ARG PYTHON_BASE_IMAGE=python:3.12-slim@sha256:423ed...99fbf
FROM ${PYTHON_BASE_IMAGE}

ENV HOME=/home/provider \
    HF_HOME=/models/cache \
    TRANSFORMERS_CACHE=/models/cache

COPY docker/qwen-provider.requirements.lock /tmp/requirements.lock
RUN python -m pip install --require-hashes -r /tmp/requirements.lock

USER provider
ENTRYPOINT ["python", "-m", "turing_agentmemory_mcp.qwen_provider"]
```

The ellipsis above is a reference to the full digest locked in
`07.1-AI-SPEC.md`; implementation must use the complete value, never this
abbreviation.

#### `docker/qwen-provider.requirements.lock` (NEW)

**Analog:** none.

The main `pyproject.toml:25-43` deliberately has only the application and GLiNER
dependency sets. Keep PyTorch/Transformers out of the main application wheel.
Create a complete transitive hash lock for:

- Sentence Transformers `5.5.1`;
- Transformers `5.14.1`;
- PyTorch `2.13.0+cpu`;
- Hugging Face Hub `1.25.1`;
- safetensors `0.8.0`;
- Pydantic `2.13.4`.

Installation must succeed with `pip --require-hashes`. A file containing only
six top-level `==` constraints is not a lock and is not sufficient.

#### `src/turing_agentmemory_mcp/qwen_provider.py` (NEW)

**Analog:** `src/turing_agentmemory_mcp/gliner_provider.py:25-101`

Copy the entrypoint lifecycle, not the GLiNER model API:

1. install SIGINT/SIGTERM handlers (`gliner_provider.py:25-38`);
2. validate every setting before import/download/model load
   (`gliner_provider.py:41-68`);
3. lazy-import heavyweight provider dependencies only inside `main`;
4. resolve a pinned cache snapshot, load exactly one assigned model;
5. construct/start the HTTP server;
6. guarantee shutdown in `finally` (`gliner_provider.py:71-101`).

The current cache-first pattern is:

```python
try:
    snapshot_path = snapshot_download(
        repo_id=model_id,
        revision=model_revision,
        local_files_only=True,
        ...
    )
except FileNotFoundError:
    snapshot_path = snapshot_download(
        repo_id=model_id,
        revision=model_revision,
        ...
    )
```

For Qwen, strengthen it: verify the resolved repository/revision, required
snapshot files, and SHA-256 before loading. A cached file with the expected name
but the wrong digest is fatal; it must not silently trigger inference.

Locked role mapping:

| `QWEN_ROLE` | Official model | Revision | `model.safetensors` SHA-256 |
|---|---|---|---|
| `embedding` | `Qwen/Qwen3-Embedding-0.6B` | `97b0c614be4d77ee51c0cef4e5f07c00f9eb65b3` | `0437e45c94563b09e13cb7a64478fc406947a93cb34a7e05870fc8dcd48e23fd` |
| `rerank` | `Qwen/Qwen3-Reranker-0.6B` | `e61197ed45024b0ed8a2d74b80b4d909f1255473` | `27cd75a405b9c1b46b59abfd88aaa209e6fed2a1972cde9b70e7659537c5e65b` |

Reject any other role. Never load both models in one process.

#### `src/turing_agentmemory_mcp/qwen_provider_http.py` (NEW)

**Analog:** `src/turing_agentmemory_mcp/gliner_provider_http.py:22-273`

This file is a necessary split even though the AI spec’s minimal layout did not
name it. The GLiNER server is already 273 lines; adding two Qwen contracts,
different role routing, nested errors, and stronger validation to the
entrypoint would create an avoidable file-size risk.

Copy:

- `ThreadingHTTPServer` with a finite `request_queue_size`
  (`gliner_provider_http.py:22-30`);
- a request-thread semaphore and a separate inference semaphore
  (`gliner_provider_http.py:30-64`);
- strict `Content-Length`, maximum body, JSON, canonical-path, and content-free
  logging helpers (`gliner_provider_http.py:149-241`);
- `json.dumps(..., allow_nan=False)` and explicit response `Content-Length`
  (`gliner_provider_http.py:175-203`);
- overload as a prompt content-free `503`, not an unbounded wait;
- one model inference in flight per role process initially. PyTorch uses its own
  CPU worker threads, so increasing Python inference concurrency is not free.

Adapt the route table:

| Role | `GET /health` | `POST /v1/embeddings` | `POST /v1/rerank` |
|---|---:|---:|---:|
| embedding | 200 when assigned model ready | enabled | 404/405 |
| rerank | 200 when assigned model ready | 404/405 | enabled |

The GLiNER error body is flat. Qwen must use the amendment’s stable nested
shape:

```json
{"error":{"code":400,"message":"invalid-request"}}
```

Never serialize exception text, input text, document text, model prompts, local
paths, or tokens.

`/health` must expose content-free immutable identity: role, model ID, revision,
resolved snapshot identity, verified model-file digest, dependency-lock digest,
instruction version, dimension/normalization for embeddings, device, and
assigned-model readiness.

#### `src/turing_agentmemory_mcp/qwen_provider_schemas.py` (NEW)

**Analog:** `gliner_provider_extraction.py:33-48,220-252,360-367`

Reuse the separation between request failures and provider failures and the
bounded-list validator. Validate before any model call:

- embeddings: object payload, known model, `input` string or list, non-empty,
  maximum 128 items;
- rerank: non-empty query, list of documents, maximum 50 documents, existing
  2,048-character per-document, 32,768 total-byte, and 8,192 estimated-token
  bounds;
- reject booleans where integers/floats are expected;
- deterministic validation errors are 4xx and never retryable.

Pydantic models may live here, but body-size and `Content-Length` enforcement
must remain in the HTTP layer before parsing.

#### `src/turing_agentmemory_mcp/qwen_provider_models.py` (NEW)

**Partial analog:** `gliner_provider_extraction.py:50-218`

Copy the narrow model protocol/adapter/provider boundary, one-time model load,
serialized top-level inference, and order-preserving batching. Do not copy
GLiNER’s extraction-specific response normalization.

Embedding contract:

```text
documents: unprefixed source text
queries: fixed English query instruction + source query
output: exactly one 1024-float row per input
        original input order and indices
        every value finite
        every row L2-normalized
```

The fixed query instruction is applied only by the application’s
`embed_query`; the provider embeds exactly the text it receives. This preserves
the existing split in `embeddings.py:69-70,103-110`.

Rerank contract:

```text
raw yes/no classification logit
    -> sigmoid exactly once
    -> finite probability in [0, 1]
    -> one row for every original document index
    -> sort by (-relevance_score, original_index)
```

There is no repository analog for the exact official Qwen pooling or yes/no
token-logit extraction. Implement those mechanics from the pinned official
model contract and cover them with deterministic fakes plus one marked real
snapshot integration test.

#### `embeddings.py`

**Analog:** existing `OpenAICompatibleEmbedder`, especially
`embeddings.py:103-179`.

Retain:

```python
def embed_query(self, text: str) -> list[float]:
    return self._embed_texts([self._with_prefix(self.query_prefix, text)])[0]

def embed_document(self, text: str) -> list[float]:
    return self._embed_texts([self._with_prefix(self.document_prefix, text)])[0]
```

Change both defaults at `embeddings.py:59,86` from 768 to 1024. Strengthen
`_parse_vectors` (`embeddings.py:163-179`) to require:

- `data` length equals request length;
- every row is an object with a unique integer `index`;
- indices are exactly `0..N-1`, then return in index order;
- every embedding is a list of exactly 1024 finite numeric values;
- each vector is unit length within a documented tight tolerance.

Do not silently `float()` strings into valid numbers. Output-shape/content
defects are deterministic provider contract failures and must not enter the
transient retry loop at `embeddings.py:138-162`.

#### `rerank.py`

- score range `[0.0, 1.0]`;

The current line `parsed.sort(key=lambda row: row.relevance_score, reverse=True)`

Keep app-side bounds visible. `bound_rerank_documents`

record truncation counts, and provider tokenization must still reject an
over-limit encoded request rather than silently changing it.

### Safe cutover operator workflow

#### `scripts/qwen_cutover.py` (NEW)

**Partial analogs:**

- `document_job_manager.py:340-346` resolves a deletion candidate and proves it
  is below the configured staging root before `shutil.rmtree`;
- `e2e_score_stubs.py:180-230` uses argument-array `subprocess.run` calls,
  checks return codes, and fails loudly on readiness timeout;
- `scripts/real_document_benchmark.py:401-408` writes JSON through `.partial`
  plus `os.replace`.

Apply those patterns to Docker resources:

1. default to dry-run;
2. obtain the Compose project identity from resolved Compose state;
3. find a volume only through exact labels
   `com.docker.compose.project=<project>` and
   `com.docker.compose.volume=<logical-name>`;
4. require exactly one result and inspect its labels/name;
5. create and verify a backup before destructive execution;
6. atomically write `cutover-manifest.json` with resolved resource names,
   labels, backup digest/location, provider identities, git SHA, and intended
   actions;
7. require separate `--execute` and exact project/target confirmation;
8. stop writers before touching canonical data;
9. remove only the manifest-recorded exact `arcadedb-data` volume or explicitly
   enumerated opaque tenant databases;
10. preserve `bertoni-data`, GLiNER cache, source tree, `.git`, `.planning`,
    `.env`, credentials, and private documents;
11. re-create ArcadeDB, wait ready, rebootstrap tenant schemas, then reingest
    only from an explicit operator-supplied source manifest;
12. verify provider health, 1024D tenant manifests, tenant isolation, and
    retrieval before declaring completion.

Forbidden implementation patterns:

```text
docker compose down -v
docker volume rm <guessed-project-prefix>_arcadedb-data
docker volume ls | glob/substring match
recursive deletion from repository root, HOME, /, /bertoni, or an env-expanded unknown path
automatic deletion of agentmemory-llama-cache
```

There is no close repository analog for exact Compose-label ownership proof or
backup-aware canonical-volume reset. Treat this as security-sensitive new code,
not a shell-command wrapper copied from README.

```python
DEFAULT_EPSILON = 0.03
```

## Shared Patterns

### Authentication and tenant isolation

The Qwen sidecars are private Compose-internal services, not tenant-aware public
APIs. The application remains the tenant boundary. Every store/E2E operation
must retain the exact non-empty `user_identifier`; the cutover utility operates
on explicitly resolved opaque databases or the exact canonical volume and must
not derive a deletion target from model output.

Apply `tests/test_tenant_server_routing.py:316-365` and
`tests/test_arcadedb_tenant_isolation.py:185-286` to every new E2E path.

### Error handling and retry classification

Reuse `provider_config.py:5,59-76` for transient HTTP statuses and nested error
messages. Network/timeout/429/503/eligible 5xx may retry with the existing
bounded policy. Invalid request, wrong role, count/order/index/width,
NaN/Inf/non-unit vector, score range, digest, revision, and manifest mismatch
are deterministic and must fail immediately.

Provider responses/logs use content-free codes. Use
`tests/test_tenant_telemetry_pseudonymity.py:224-231` as the serialized-canary
pattern.

### Validation and determinism

- JSON serialization uses `allow_nan=False`.
- Embedding response order is reconstructed from complete unique indices.
- Rerank order is `(-score, index)`.
- Every batch cap is checked before inference.
- Benchmark/cutover JSON is written with sorted keys through a `.partial` file
  and `os.replace`.
- Benchmark verdicts require repeated runs and exact identity/corpus matches.
- Stable generation/index names derive from one dimension/generation input.

### Model and cache integrity

Pinned repository revision plus a matching filename is not sufficient. Verify
the model bytes before loading and expose the verified values in health. The
snapshot’s required config/tokenizer files also need an integrity manifest or
tree identity derived during implementation; do not invent their digests.

Never report the pinned **base image** digest as the complete built Qwen image
digest.
